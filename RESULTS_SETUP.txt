RESULTS 自動更新セット
======================

GitHub のルート（index.html や style.css と同じ場所）に次の3ファイルを置いてください。

1. results.html
2. match.html
3. results.xlsx

既存の style.css と site.js はそのまま使用します。

更新方法
--------
今後は results.xlsx の1シート目に試合を1行追加・修正して、
同じファイル名 results.xlsx でGitHubへ上書きするだけです。
results.html のHTMLを毎回編集する必要はありません。

1シート目の必須列
----------------
MatchID / Team / Date / Category / Round / Opponent / YCU / Opp / Result / Youtube

Team:
MEN / WOMEN / NURSING

Category:
League / 東医体 / Practice（または 練習試合）

Youtube:
空欄でも可。URLを入れると
・LATEST RESULT = 右側サムネイル
・公式戦 = HIGHLIGHTSアイコン
・練習試合 = YouTubeアイコン
が自動表示されます。

詳細ページ
----------
FULL RESULT を押すと match.html?id=MatchID に移動します。
男子部 2026 / 女子部 2026 / 看護部 2026 の詳細シートを読み、
D1, D2, ... / S1, S2, ... を自動表示します。

重要
----
詳細シート内の試合順と、Sheet1の各チームの試合順は同じ順番にしてください。
現在のExcelはこの条件を満たしています。

ローカルプレビュー
------------------
GitHub Pagesでは results.xlsx を自動で読み込みます。
PCでHTMLを直接開く場合は、ブラウザの制限でExcel自動読込に失敗することがあります。
その場合、画面に出るファイル選択から results.xlsx を選べば確認できます。
